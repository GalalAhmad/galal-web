## 4. قائمة الأسرار والمفاتيح الإلزامية للتدوير الفوري (Secrets Rotation Checklist)

لحماية النظام بنسبة 100% ومنع أي استغلال للمستودع خلال فترة إتاحته كـ Public، يجب تدوير المفاتيح التالية فوراً من لوحات التحكم السحابية الرسمية:

- [ ] **1. مفاتيح Supabase API:**
  - الانتقال إلى لوحة تحكم Supabase (`Project Settings -> API`).
  - تدوير مفتاح `SUPABASE_SERVICE_ROLE_KEY` (Generate New Key).
  - تحديث مفتاح `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
- [ ] **2. مفتاح توقيع الجلسات المشفر (SESSION_SECRET):**
  - توليد قيمة عشوائية جديدة بطول 64 محرفاً عبر الأمر:
    ```bash
    node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
    ```
  - تعيين القيمة الجديدة في متغيرات بيئة Vercel/Production لإبطال أي توكنات جلسة سابقة تلقائياً.
- [ ] **3. كلمات مرور الإدارة والمعالج:**
  - تعيين كلمات مرور جديدة فريدة ومعقدة.
  - توليد تجزئة PBKDF2 المحدثة (210,000 دورة) عبر `hashPassword()` وتخزينها في:
    - `ADMIN_PASSWORD_HASH`
    - `COUNSELOR_PASSWORD_HASH`
- [ ] **4. مفاتيح خدمات البريد الإلكتروني (Resend / SMTP):**
  - تدوير أي مفاتيح `RESEND_API_KEY` أو بيانات خادم SMTP مستخدمة في المشروع.
- [ ] **5. مفاتيح Sentry وخرائط المصدر:**
  - تدوير `SENTRY_AUTH_TOKEN` في لوحة تحكم Sentry.

## 5. خطة تطهير تاريخ المستودع (Repository History Rewrite Plan)

تم إيقاف تتبع الملفات في شجرة العمل الحالية. ولإزالة السجلات نهائياً من الـ commits القديمة، نوصي بتنفيذ الخطوات التالية بعد التنسيق مع الفريق:

1. أخذ نسخة احتياطية كاملة للمستودع (تم إنشاؤها بوسم `backup-before-security-first`).
2. تشغيل أداة `git-filter-repo`:
   ```bash
   git filter-repo --invert-paths \
     --path src/data/bookings.json \
     --path src/data/feedback.json \
     --path src/data/inquiries.json \
     --path src/data/userProfiles.json \
     --path src/data/subscribers.json
   ```
3. إعادة رفع الفروع إلى مستودع GitHub الخاص مع الأمر `--force`.
4. إخطار جميع المساهمين بإعادة استنساخ المستودع بعد إعادة كتابة التاريخ.
