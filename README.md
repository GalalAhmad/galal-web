## 🎯 نبذة عن المنصة والهوية
الموقع مصمم وفق أحدث معايير تجربة المستخدم (UI/UX) وبأسلوب بصري هادئ مستوحى من كبرى المنصات العلاجية العالمية (عرب ثيرابي):
- **الألوان المعتمدة:** الأخضر الهادئ (`#4E7E76`)، الأزرق الموثوق (`#154F9C`)، البرتقالي الدافئ (`#D97706`)، والمرجاني الاستثنائي للحجوزات (`#CC4E46`).
- **اللغة والاتجاه:** لغة عربية فصحى دافئة، وتصميم كامل اليمين-إلى-اليسار (RTL 100%) متوافق مع كافة أحجام الشاشات.
- **السرية والأمان:** ربط الحجوزات المباشرة والتنسيق الآمن عبر Google Meet واتصال الواتساب الرسمي المشفر.

## ⚙️ أماكن تعديل المحتوى والإعدادات

### 1. الأسعار ومعلومات التواصل وموعد دفعة ميثاق:
- **الملف:** `src/data/siteSettings.json`
- يمكنك تعديل أي حقل من هذه الحقول إما يدوياً أو مباشرة من [لوحة التحكم](/admin):
  ```json
  {
    "siteName": "جلال أحمد",
    "phone": "+20 101 487 6666",
    "whatsapp": "201014876666",
    "email": "info@galalahmad.com",
    "cancellationPolicyHours": 48,
    "calendlyUrl": "https://calendly.com",
    "individualFee": "تبدأ من 250 ر.س",
    "maritalFee": "تبدأ من 350 ر.س",
    "parentingFee": "تبدأ من 250 ر.س",
    "emergencyFee": "500 ر.س",
    "mithaqNextBatch": "نوفمبر 2026"
  }
  ```

### 2. إضافة مقطع فيديو جديد في قسم المرئيات:
- **عبر لوحة التحكم:** ادخل إلى `/admin` ← تبويب **المرئيات والفيديوهات** ← أدخل عنوان الفيديو، ورابط اليوتيوب، والتصنيف، ثم اضغط "إضافة الفيديو".
- **يدوياً عبر الكود:** افتح `src/data/videos.json` وأضف عنصراً جديداً في بداية المصفوفة:
  ```json
  {
    "id": "v7",
    "title": "عنوان الحلقة الجديد",
    "category": "quran",
    "categoryLabel": "مشروع أقومية القرآن",
    "youtubeId": "كود_الفيديو",
    "youtubeUrl": "https://www.youtube.com/watch?v=كود_الفيديو",
    "duration": "12:30",
    "publishDate": "20 أكتوبر 2026",
    "viewsCount": 100,
    "desc": "ملخص محتوى الحلقة..."
  }
  ```

### 3. إضافة أو تعديل مقال في المنتدى الفكري:
- **الملف:** `src/data/articles.ts`
- أضف مقالاً جديداً داخل مصفوفة `initialArticles`. سيتم تلقائياً إنشاء صفحة مستقلة ومفهرسة له تحت الرابط: `/articles/[id]`، وإضافتها لخريطة الموقع `sitemap.xml`.

### 4. إضافة أو تعديل اختبار نفسي:
- **الملف:** `src/data/testsData.ts`
- يحتوي على 41 مقياساً مستنداً للأدوات العالمية (PHQ-9, GAD-7, MBI, DAS, etc.).
- كل اختبار يتضمن معرّفه `id`، أسئلته الإكلينيكية، خيارات الإجابة والدرجات، والتفسيرات المقترحة.

## 🔒 لوحة التحكم الإدارية المحمية (/admin)
تم تأمين لوحة التحكم ببوابة تسجيل دخول مشفرة ومحمية بكلمة مرور خاصة بالمستشار فقط:
- **الرابط:** `https://galalahmad.com/admin`
- **كلمة المرور الافتراضية:** `galal@admin2026` (أو `galalahmad2026`)
- **الأقسام المتاحة للتحكم:**
  1. **الرسائل والطلبات المؤسسية:** متابعة طلبات المدارس وتحديث حالتها أو الرد عليها عبر واتساب بنقرة واحدة.
  2. **الآراء والتقييمات:** اعتماد تجارب العملاء الواردة ونشرها في الصفحة الرئيسية وصفحة الخدمات، ومولد رسائل طلب التقييم للواتساب.
  3. **الأسعار والخدمات:** تعديل نطاق أسعار الاستشارات الفردية، الزوجية، التربوية، والطارئة.
  4. **المسارات والدفعات:** تعديل مواعيد انطلاق الدفعات القادمة لبرنامج ميثاق وحالات التسجيل.
  5. **المرئيات والفيديوهات:** إضافة مقاطع يوتيوب جديدة أو حذف المقاطع المنشورة.
  6. **الإعدادات والتواصل:** تعديل أرقام الهواتف، البريد، وسياسات الإلغاء.

## 🔍 إصلاحات الـ SEO والصفحات الثابتة وخريطة الموقع
1. **صفحات ثابتة فردية للمقالات (`/articles/[slug]`):**
   - توليد من جانب الخادم (SSG/SSR) عبر `generateStaticParams`.
   - وسوم Meta وبيانات Schema مهيأة بالكامل لقراءة محركات البحث و Googlebot.
2. **صفحات ثابتة فردية للاختبارات (`/tests/[slug]`):**
   - توليد من جانب الخادم (SSG/SSR) لجميع الـ 41 مقياساً.
   - بادجات الأدوات الإكلينيكية المعيارية (PHQ-9, GAD-7, MBI, DAS, ASRS...).
   - صناديق طوارئ إلزامية للاختبارات الحساسة (الاكتئاب، ثنائي القطب، الفصام، ما بعد الصدمة).
3. **عناوين فريدة و Meta Descriptions:**
   - `/faq` ← "الأسئلة الشائعة | جلال أحمد"
   - `/contact` ← "تواصل معنا | جلال أحمد"
4. **خريطة الموقع التلقائية (`/sitemap.xml`):**
   - مولدة ديناميكياً من `src/app/sitemap.ts`.
   - تغطي كافة الصفحات الرئيسية، وجميع المقالات، وجميع الاختبارات الـ 41، وقسم المرئيات، وأقومية القرآن.

## 📱 تطبيق الويب التقدمي (PWA) والتثبيت على الهواتف
تم تحويل الموقع بالكامل إلى تطبيق ويب تقدمي قابل للتثبيت على الهواتف المحمولة:
1. **ملف المانيفست (`public/manifest.json`):**
   - يدعم التثبيت المباشر (`display: standalone`)، التوجيه الرأسي، والاتجاه RTL.
   - أيقونات واضحة بدقة 192×192 و 512×512 وشعار أبل 180×180 بخلفية الهوية.
2. **عامل الخدمة (`public/sw.js`):**
   - استراتيجية **Network-first** للصفحات لضمان حصول الزائر على أحدث محتوى واستشارات.
   - استراتيجية **Cache-first** للصور والخطوط وملفات التصميم لتحميل فائق السرعة في الزيارات المتكررة.
3. **لافتة التثبيت الذكية (`PWAInstallPrompt.tsx`):**
   - تعمل على هواتف **أندرويد** وتلتقط حدث التثبيت بضغطة زر.
   - تقدم دليلاً إرشادياً لطيفاً لمستخدمي **آيفون / Safari** ("مشاركة ← إضافة إلى الشاشة الرئيسية").
   - تظهر للموبايل فقط بعد مرور 15 ثانية دون إزعاج.
   - تُخفي نفسها نهائياً لمن يقوم بإغلاقها بحفظ الخيار في `localStorage`.

## 🚀 خطوات التطوير، البناء، وإعادة النشر

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. التشغيل في بيئة التطوير:
```bash
npm run dev
```

### 3. بناء النسخة الإنتاجية (Production Build):
لضمان عدم نفاد ذاكرة Node.js أثناء فحص الأنواع وبناء جميع المسارات الثابتة، يُفضل تشغيل أمر البناء بالحد المناسب للذاكرة:
```powershell
$env:NODE_OPTIONS="--max-old-space-size=4096"; npm run build
```

### 4. تشغيل خادم الإنتاج:
```bash
npm run start
```

### 5. النشر على GitHub:
```bash
git add .
git commit -m "feat: updates"
git push origin main
```
