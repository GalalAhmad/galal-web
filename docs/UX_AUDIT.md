## 3. مراجعة الاتساق البصري ونظام الرموز التصميمية (Design Tokens)

### أ. تماثل الاتجاه العربي (RTL Symmetry)
- وسم الجذر مضبوط بشكل صحيح على `<html dir="rtl" lang="ar">`.
- الأيقونات الاتجاهية والأسهم تشير للجهة المنطقية الصحيحة لمسار القراءة العربي (الأسهم تشير لليسار `←` للانتقال للأمام).
- تم استخدام الخصائص المنطقية CSS (`start` و `end` و `ms-` و `me-`) في المكونات الأساسية.
